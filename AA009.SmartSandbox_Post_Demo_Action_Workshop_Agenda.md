# SmartSandbox Post-Demo Review & Action Workshop

## Purpose

Following the SmartSandbox demo review, this workshop aligns SmartMock,
PSD2/Open Banking, and DAC SMEs on the evidence required to make an
architecture decision.

The objective is to evaluate:

**Option A** HSBC Developer Portal + DAC Sandbox

versus

**Option B** HSBC Developer Portal + SmartMock / SmartSandbox

The goal is not only feature comparison, but understanding functional
capability, operating model, cost, and strategic fit.

------------------------------------------------------------------------

# Attendees

## SmartMock SME

Focus: - Current SmartMock capability - Internal adoption - OpenAPI
onboarding - Dynamic mock data - Self-service model - SmartSandbox

## PSD2 / Open Banking SME
